## Sections

- **Home** — Introduction and quick links to download my resume or get in touch
- **About** — My background, academic journey, and what drives me as a developer
- **Skills** — Technologies and tools I work with daily

- **Education** — My academic journey and qualifications

- **Contact** — A working contact form plus my email, location, and social links

- Consistent theming system built with CSS custom properties

## Featured Project: Aero

A multi-page PHP/MySQL footwear e-commerce application featured in the Portfolio section, including:
- Secure sign-up and sign-in
- A footwear listing page with a reusable card component
- A search feature using PDO prepared statements with `LIKE`-based queries
- Password hashing and input validation to guard against SQL injection and XSS
